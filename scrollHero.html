La Magia del CSS

El contenido desliza sobre
el fondo estático.

Este efecto se logra usando una combinación muy sencilla de CSS. El Hero (la imagen de arriba) tiene una posición fija (position: fixed) y ocupa el 100% de la altura de la pantalla. Luego, este contenedor blanco donde estás leyendo tiene un margen superior del 100% del alto de la pantalla (margin-top: 100vh) y una posición relativa para poder pasar por encima.

Súper Ligero

No requiere librerías complejas de JavaScript. Todo el trabajo pesado lo hace el motor de renderizado del navegador con CSS puro.

Altamente Visual

Es perfecto para portafolios, páginas de aterrizaje (landing pages) y sitios corporativos modernos que buscan impresionar al usuario.
